维护角色：C；姓名由组内绑定。日期：2026-11-06。状态：待实现；本次压缩包不包含测评、人工面试或培训业务接口。

先读根 AGENTS.md、README、更新记录、四个角色最新交接、目标路径规则及[统一需求 V2.2](../docs/需求文档.md)。接入事实见[C 契约基线](../docs/modules/C/源码接入基线.md)、[接入决策](../docs/源码接入与需求决策.md)和[来源参考区](../docs/imports/hhy_gycs_master/README.md)；全组安排见[四人分工](../docs/四人分工与试行方案.md)。本任务的 C 归属不从工具名或分支推断。

## 继承的目录与依赖

保留 backend/app/modules/assessments、interviews、training 及 frontend/src/features 同名既有空目录；已登记的 Next.js App Router 业务路由按需实现，不换前端框架，不把空目录或占位页面算作完成。复用 A 的登录/岗位、B 的现有人才主档与快照、D 的模型/任务/轮询，不另造公共设施。

写入路径的唯一机器来源是[ownership.json](../.collaboration/ownership.json)，不复制完整通配清单或通过任务卡扩权。Next.js 公共布局与路由骨架仍归 A，业务页面由 C 提供并请求 A 接入入口；模型/任务框架及公共 schema/加载注册归 D。

## 剩余任务

1. 建题库、岗位出题/管理员确认、测评配置与分配，提供个人逐题答题；客观题正确计分，简答真实 AI 评分并允许人工复核。
2. 按已答表现、知识点覆盖与剩余题量动态选下一题，保存题目/答案快照、选题输入和理由；设置有界结束条件，避免重复题、无限循环及随机抽题冒充自适应。
3. 评分未完成不提前进入依赖它的下一题；支持刷新恢复、重复提交幂等、失败重试、错题复习、能力分析及历史。记录实际满分、归一化口径和人工修分，不回改历史选题路径；复测形成新记录。
4. 一期只做人工面试安排与结构化反馈：岗位、人员、面试人、时间、状态、记录和人工评价，先登记字段及可见范围。与 A 的招聘引用衔接，内部评价不自动向本人开放；未参加不生成评价。AI 文字提问、追问、会话和自动面试评价放二期。
5. 建真实课程、AI 培训草稿、管理员编辑分配、个人学习状态/备注及成长历史。推荐不存在的课程时提示缺口，个人手动完成明确为自报，不当作真实学时证明。课程审批/候补、九宫格等新增来源扩展仍待确认。

## 跨包依赖与交付接口

A 提供服务端用户上下文、本人数据授权、岗位版本、招聘/人工面试关联及入口；B 提供 talent_profile_id 到 person_id 映射、档案版本与原文证据，C 不建立第二套人才主档。D 提供真实模型、任务状态、失败处理及“测评完成→能力分析→培训草稿”固定流程，流程不自动分配培训。

C 维护测评/培训业务提示与评分语义，需要 D 的 loader/schema/任务注册变更时请求对方实施。向 D 提供测评通过率、人工面试与学习指标口径，列明分母、去重键、时间、允许维度及权限，区分未参加、作答中、评分中、失败、完成和未通过。契约写 docs/modules/C/，跨包请求写 docs/requests/C/。

## 验收与检查点

管理员发布测评，两个个人账号只能访问自己的任务；同一初始条件下答对/答错路线产生可解释的后续选题变化，不重复题。刷新与失败重试不丢答案或重复评分，管理员及本人看到一致成绩，未作答题答案不泄露。人工面试可安排、更新和填写反馈，招聘侧可关联，可见范围正确。培训使用实际课程及真实输入，个人更新后管理端可查，历史不覆盖。

3–4 天为首轮检查窗口：先落实题库/状态、人工面试与跨包契约，再用两条动态路线和双端权限探针评估剩余工作，不保证全范围四天完成。外部运行探针未执行，C 模块尚无本轮业务验收证据，来源 588 项测试也不覆盖 C 新模块验收。
