## 读取优先级

通用配置（除 `task_concurrency` 外的所有键）：

```
1. 环境变量（.env + 系统环境变量）   → 最高
2. config.py 硬编码默认值            → 兜底
```

`task_concurrency` 特例（架构 §5.4/§5.6、数据库 §3.2）：

```
1. sys_settings.task_concurrency（表有值时）        → 最高，页面改完立即生效、重启后仍是新值
2. 环境变量 TASK_CONCURRENCY                        → 仅 init_db 首次种子 + 表缺行时兜底
3. config.py 默认值 2                               → 最后兜底
```

> 注意：如果按“env 最高”处理，页面把并发改成 4 后，重启会被 `.env` 里的 2 覆盖，这与架构 §5.4 的“热改”语义相反。实现上 `Settings.task_concurrency` 只作兜底，`load_runtime_overrides()` 启动时读表覆盖它。

`sys_settings` 只承载 `task_concurrency`（架构 §5.4/§5.6、数据库 §3.2）。其余配置只在 `.env`，改后重启生效。

## `sys_settings` 种子（`init_db.py`，数据库 §3.2/§9）

```sql
INSERT INTO sys_settings (setting_key, setting_value, value_type, description)
VALUES ('task_concurrency', '2', 'int', 'TaskRunner 全局任务并发（1-5）');
```

- 字段名是 `setting_key / setting_value / value_type / description`，不是 `key/value`。
- 已存在则**保留现值**，不用 `.env` 覆盖用户改过的值。
- 合法范围 1–5，越界返回 400（接口 §4 `PATCH /resumes/queue/settings`）。
- 并发语义：三类任务共用一个 `ThreadPoolExecutor`；`task_concurrency` 是全局上限，不是"解析/筛选/匹配各一份"。

## `config.py` 加载伪代码

```python
class Settings(BaseSettings):
    # LLM / Embedding
    llm_base_url: str
    llm_api_key: str
    llm_model: str = "deepseek-chat"
    llm_timeout: float = 120.0
    llm_concurrency: int = 2
    embedding_base_url: str | None = None
    embedding_api_key: str | None = None
    embedding_model: str = "text-embedding-v3"
    embedding_query_cache_ttl: int = 300
    embedding_timeout: float = 10.0
    vector_sync_timeout: float = 1.5
    prompt_version: str = "v1.0"

    # MySQL
    mysql_host: str = "localhost"
    mysql_port: int = 3306
    mysql_user: str = "root"
    mysql_password: str
    mysql_db: str = "ai_talent"

    # Milvus
    milvus_uri: str = "http://localhost:19530"
    milvus_collection: str = "talent_vectors"

    # JWT
    jwt_secret: str
    jwt_expire_hours: int = 24

    # TaskRunner
    task_concurrency: int = 2
    runner_scan_interval: float = 2.0
    task_heartbeat_timeout: int = 600  # 10 分钟
    task_shutdown_timeout: int = 30
    upload_dir: str = "./data/uploads"
    cors_origins: str = "*"

    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    def load_runtime_overrides(self) -> None:
        """启动时只覆盖 task_concurrency；其余项不读 DB"""
        from dao.sys_settings import get_value
        value = get_value("task_concurrency")
        if value is not None:
            self.task_concurrency = int(value)

settings = Settings()
```

> `extra="ignore"` 而不是 `forbid`：`.env` 里允许存在前端键/临时键，避免启动失败。`EMBEDDING_BASE_URL` 为空时在 `embedding_client` 初始化处回退到 `llm_base_url`。
