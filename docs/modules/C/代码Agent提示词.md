## 已确认业务范围

1. 招聘及员工都支持岗位笔试：招聘依据应聘岗位，员工默认当前岗位或管理员指定目标岗位；用途、方案和结果分别保存。
2. 两种测评均为固定岗位标准、固定题量和难度结构，不按作答表现升降难度。管理员选择专业维度，可选通用维度，配置成绩权重和每次总分线；维度分别百分制，加权得百分制总分，不设维度最低分。题数由系统简化分配，不能漏掉考核维度或题库不足仍假装发布成功。
3. 使用经管理员确认的题库，单选客观计分，简答真实 AI 评分并允许人工修分。保存试卷/答案/评分与输入版本；刷新恢复，交卷幂等，模型失败不计零分，不重复创建结果。评分/计分细节按细化草案明确的建议实施并记录。
4. 招聘成绩由管理员确认后向本人公布，员工评分完成即可查看。成绩公开绑定结果版本：修分重算维度、总分和通过结论，招聘新版须再次确认；标准答案、错题解析开放与分数公开分别控制。复测、复习事项及历史快照保留。
5. 管理员手动新增多轮人工面试，各轮保存时间、面试人、状态、评价、事实依据、优势不足及推进建议；不计算面试总分，不自动合并笔试/面试分或推进招聘状态。反馈仅管理员及获授权面试人可见，候选人只看本人安排与公开招聘进度。
6. 培训计划仅员工可用。真实课程目录配合岗位/档案/测评结果生成 AI 草稿，管理员编辑确认分配；课程不足明确缺口，不编造链接。员工学习状态为自报，保留课程/计划版本及成长历史，不宣称验证学时、不自动更新能力评级。
7. 候选人入职后由管理员关联员工身份，保留旧测评，再人工分配培训；不自动公开内部面试或未公布成绩。固定流程仅员工测评进入培训草稿分支，招聘测评不生成候选人培训，草稿不自动分配。

不加入 AI 面试、自适应选题、音视频、监考、人脸、防挂机、课程审批候补、九宫格、自动报名或自动人事决策。未确认的后续功能不是一期交付。
