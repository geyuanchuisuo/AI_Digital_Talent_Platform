## 1. 范围与采用方案

一期交付岗位笔试、多轮人工面试、员工培训及成长记录。招聘测评与员工测评共用基础功能，按用途分别配置和保存结果。招聘以本次应聘岗位为依据；员工默认当前岗位，管理员可指定目标岗位。

两类测评均采用固定岗位标准和固定难度结构，不随作答表现调整题目难度。此前讨论过自适应选题，用户基于企业选人目标选择固定结构；因此不开发升降难度与能力估计机制，不把随机抽题称为自适应。自适应是否后续实施未确定。AI 面试与可编辑工作流已放二期，非本包当前交付。

人才九宫格/人才池、课程审批/候补、自动报名、学习监控、有效学时证明、音视频面试与自动人事决策未纳入本包一期。笔试结果、面试建议分别保存，由授权人员决定招聘推进，不合成所谓最终录用分。

## 2. 已确认的业务规则

| 编号 | 规则 |
|---|---|
| C-ASM-01 | 管理员按岗位选择专业能力维度，通用能力按需选配；不强制所有岗位同一组维度 |
| C-ASM-02 | 管理员配置固定总题量、各维度成绩权重及总分线；权重合计 100%，不设置维度单独通过线 |
| C-ASM-03 | 一期各维度题数由系统自动分配，不要求管理员精细配置题数；题数比例不必等于成绩权重 |
| C-ASM-04 | 正常完成时题量固定，同岗位同方案具有一致的维度、题量、难度结构与评分标准 |
| C-ASM-05 | 单选与简答沿用既有范围；单选客观评分，简答调用真实模型按评分说明评分，支持管理员复核 |
| C-ASM-06 | 各维度折算百分制后按配置权重合成百分制总分；各维度成绩分别保留用于分析 |
| C-ASM-07 | 招聘成绩由管理员确认后向本人公布；员工成绩在评分完成后本人即可查看 |
| C-INT-01 | 管理员手动新增多轮面试，各轮独立保存时间、面试人员、状态、记录与反馈，不强制固定三轮 |
| C-INT-02 | 面试记录评价、事实依据、优势、不足和推进建议，不另计面试总分；建议为建议推进/待定/不建议推进 |
| C-INT-03 | 反馈仅管理员及获授权面试人员可见；候选人仅查看本人安排与明确公开的招聘进度 |
| C-TRN-01 | 培训计划一期仅面向员工；候选人入职后由管理员关联员工身份，再分配培训 |
| C-TRN-02 | AI 依据真实岗位、档案或测评结果及实际课程生成培训草稿；管理员可编辑并确认分配 |
| C-TRN-03 | 员工记录未开始/学习中/已完成及备注；完成为学习自报，不代表验证学时或自动变更能力评级 |

## 3. 笔试流程与实施建议

流程：维护题库 → 建测评草稿 → 确认试卷与评分规则 → 发布并分配 → 本人作答 → 评分/必要复核 → 按场景公布 → 查看结果与复习。

以下为一期简化设计，尚非用户逐项指定的参数；整体审阅可调整，无需继续逐字段询问：

- 题目至少保存岗位、维度/知识点、难度、题型、题干、选项（适用时）、标准答案/参考答案与评分说明。AI 生成题目须管理员审核入库。
- 系统先给每个维度至少一题，其余题量按权重分配、取整补足总量。总题量小于维度数时提示调整。默认使用中等题组卷；需要混合难度时在管理员预览确认的试卷中冻结结构，不增加升降难度配置界面。
- 从已审核题库生成固定试卷，发布时保存题目与评分说明快照；同一测评方案版本使用同一套试卷，候选人与员工的不同用途可分别建方案。发布后不因答对/答错临时换题。题库不够则阻止发布并指出缺口，不能临时用未审核模型题填充。
- 一期不增加考试倒计时、监考或切屏检测。本人可逐题保存、刷新恢复；交卷前提示未答题，确认提交后未答题按零分。交卷幂等，提交后不继续修改答案。
- 维度得分按该维度实际所得分/满分×100计算；题目默认相同满分，简答按评分说明归一化。总分为维度百分制分数按权重加权；先保留计算精度，按未舍入总分与分数线比较，显示到小数点后两位。达到总分线（含相等）标记笔试通过，未达到标记笔试未通过；不触发自动关闭招聘申请。
- 评分失败仅重试失败项，已完成答案与成功评分保留，不能以零分冒充模型失败。未完成评分不生成最终通过结论，不公布半成品；管理员复核保留原分数、理由、修改人和时间。
- 招聘成绩公布前仅授权管理人员可见；员工在评分完成后本人可见。默认招聘标准答案及错题解析由管理员统一开放，避免候选人在同批测评结束前获得答案；员工评分完成后可复习本人题目。答案开放是独立字段，不能与分数发布混用。
- 管理员可另分配一次复测，形成新记录；新旧成绩分别保存，不覆盖原试卷、答案或历史。中止/撤销另记状态，不伪装正常完成。
- 保留既有错题与复习范围：本人可查看已获准开放的错题和复习事项，标记复习完成；每项关联原答题/题目快照，后续改题或复测不覆盖该依据。招聘答案尚未开放时不借复习入口提前泄露。

## 4. 面试流程与反馈

流程：关联候选人及岗位 → 新增面试轮次 → 安排时间/方式/面试人 → 记录开展或取消 → 填写结构化反馈 → 授权招聘人员查看并决定推进。

实施建议：每轮保存轮次名、时间、方式/地点或会议链接、面试人员、待进行/已完成/已取消状态、内部备注、反馈作者及更新时间。可改期或取消并保留变更记录。没有开展的面试不允许标记“已完成反馈”；不采集音视频或生成 AI 评价。

面试人员按 A 提供的资源授权访问相应轮次与必要档案，不因被安排为面试人就获得全部人才访问权。内部评价、推进建议不进入候选人接口、导出或公开进度字段。C 向 A 提供面试安排与内部反馈引用，招聘最终状态仍由 A 维护。

## 5. 培训与成长流程

流程：维护真实课程 → 选择员工及岗位/测评输入 → AI 生成草稿 → 管理员编辑确认并分配 → 员工查看材料和更新学习状态 → 管理端查询 → 成长历史留存。

课程至少保存标题、介绍、材料文件或链接、适用能力维度及有效状态；不新建完整视频平台。推荐只选课程库实际有效且有权限访问的课程，缺课列缺口，不生成假链接。无测评记录时可基于有效档案/岗位生成建议，必须说明未使用测评证据；资料不足或模型失败明确提示。

课程与培训计划保留版本，已分配计划绑定当时的课程/材料与安排快照。后续编辑形成新版本，不用当前课程内容静默替换历史计划或学习记录；失效材料说明状态并提供管理员处理入口。

一期草稿不自动分配、报名或修改能力评级。学习状态由员工自报，管理员可查看；复测和学习事件按时间追加。能力图注明来自何次测评及维度口径，缺测维度显示未评估，不把学习完成直接换算为能力提高。

候选人没有培训计划访问/分配权限，后端须校验员工身份，不能只隐藏前端按钮。身份关联沿用同一人才主档，保留历史测评引用；入职不自动公开内部面试反馈或此前未公布的招聘成绩。

## 6. 数据与接口边界

拟有实体：题库题目、测评方案/版本、固定试卷/题目快照、人员分配、答题及题目评分、结果版本/公开状态、面试轮次/反馈、课程、培训草稿/计划、课程学习记录、成长事件。以上是待设计实体，不宣称已建表或接口。

共用关联为 person_id（先映射现有 talent_profile_id）、user_id、job_id/job_version、person_version；身份及访问范围由后端解析，不能由请求自报。题库、试卷、岗位、档案、模型、提示和评分规则版本关联结果快照。

测评执行状态与成绩公开状态分开：待开始/作答中/评分中/已完成/已撤销；模型失败记录到评分项或任务，支持重试。招聘另有待确认公布/已公布。学习状态为未开始/学习中/已完成；任务框架的 pending/running/done 等状态需按 D 契约映射，不直接全仓重命名。

同一提交、交卷、评分重试、反馈保存及培训分配使用服务端幂等键/唯一约束。新版本修改既有成绩需保留历史，避免页面回看使用当前题库或模型重算旧结果。实际路由、字段、迁移及幂等键在接口设计阶段确定。

成绩修改后重新计算维度分、总分及笔试通过结论，生成新结果版本。招聘“已公布”绑定具体结果版本，新版须管理员再次确认才能公开；此前公开的旧版可保留本人历史查看，未确认新版仅内部可见，不沿用旧版公开标记。员工新版评分完成即可本人查看，同时保留版本和修订时间。此为落实 C-Q13 的设计细则，不要求新增审批流程。

## 8. 验收场景

| 场景 | 必须观察的结果 |
|---|---|
| 两种测评 | 招聘按应聘岗位、员工按当前或指定目标岗位；用途及结果独立留存 |
| 固定结构 | 同方案作答对错不改变后续题目；题量/维度覆盖符合发布快照，题库不足不能发布 |
| 算分与分数线 | 维度百分制和权重总分可人工复算；总分等于线通过；没有维度淘汰线 |
| 交卷及失败恢复 | 刷新答案保留，重复交卷不重复评分；模型失败不当零分，恢复只补失败项 |
| 公开边界 | 招聘公布前本人不可见，管理员公布后可见；员工评分完成即可见；第二账号无法访问 |
| 人工复核及复测 | 原评分/修改记录可追溯，复测不覆盖旧结果或改变旧试卷 |
| 修分与公布版本 | 新分数重新算总分和结论；招聘新版确认前本人看不到，员工新版评分完成即可见 |
| 错题复习 | 标记复习完成可持久化，仍关联原答题快照；招聘答案开放前不泄露 |
| 多轮面试 | 可增加不同轮次、改期、取消与记录反馈；内部反馈只给授权人员，不生成面试总分 |
| 员工培训 | 真实课程生成草稿，人工确认分配后本人可看，学习自报更新后管理端可查 |
| 课程/计划版本 | 后续编辑生成新版，旧计划与学习记录仍显示当时课程及安排依据 |
| 对象隔离 | 候选人不能取得培训计划；关联员工身份后需人工分配，历史引用保留且内部反馈不泄露 |
| 固定流程 | 员工测评可产生培训草稿；招聘测评不产生候选人培训，不自动分配/报名 |
