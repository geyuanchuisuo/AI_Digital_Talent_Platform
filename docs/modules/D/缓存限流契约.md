# D 缓存/会话/限流契约（T-D01，v1.0）

> 版本：v1.0　|　日期：2026-11-07　|　维护：D　|　上游：统一需求 V2.6 §1（Redis 强制栈）、DEC-20261107-DLINE-CONFIRMED（Redis 故障降级直查库）
> 实现：`backend/app/core/cache/`（client.py + ratelimit.py）；测试：`tests/D/test_cache.py`、`tests/D/test_ratelimit.py`、替身 `tests/D/fake_redis.py`

## 1. 配置项（`backend/app/config.py` 新增，均有默认值）

| 键 | 默认 | 说明 |
|---|---|---|
| `REDIS_URL` | `""`（空） | 空 = 未启用：缓存读写与限流全部降级，应用行为与无 Redis 时一致 |
| `RATE_LIMIT_PER_MINUTE` | `120` | 单一客户端固定窗口默认限值（中间件构造参数可覆盖） |
| `RATE_LIMIT_WINDOW_SECONDS` | `60` | 固定窗口长度 |
| `RATE_LIMIT_BLACKLIST_TTL` | `3600` | 黑名单默认时长（写黑名单方决定，此处为默认值） |

## 2. 键空间与序列化

- 三类键前缀隔离：`aitalent:{kind}:{key}`，kind ∈ `session` / `data` / `ratelimit`；kind 白名单外直接抛 `UnknownCacheKind`（调用方 bug，不降级）。
- 黑名单挂 ratelimit 类：`aitalent:ratelimit:blacklist:{identity}`；限流计数：`aitalent:ratelimit:count:{identity}`。
- 值一律 JSON（`ensure_ascii=False`）；`set(kind, key, value, ttl=)`；`get` 未命中/未启用/不可用一律 `None`。
- 身份取 `X-Forwarded-For` 首段 IP，缺失回退 client host；user 级限流在鉴权接入 request.state 后由后续任务扩展。

## 3. 降级语义（验收②的核心）

1. **未配置 REDIS_URL**：`CacheClient.enabled=False`，中间件直通（不进限流逻辑）。
2. **Redis 连接失败**：一次失败即进入 5 秒探测冷却（可配），冷却期内不触网；黑名单视为不存在、计数放行、读写按 miss——**核心接口保持 200，不得因缓存故障失败**。
3. `incr_window` INCR 与 EXPIRE 非原子：窗口键若因宕机残留无 TTL，下次计数时检测 `ttl==-1` 自动补窗口（自愈）。
4. 降级 warning 最小间隔 30s，防日志刷屏。

## 4. 中间件行为（挂载归 A）

- `app.add_middleware(RateLimitMiddleware)`；豁免路径默认 `/api/health`。
- 超限：**429** + `Retry-After`（窗口秒数）+ 统一错误体结构 `{code, message, data: null, request_id}`。
  ⚠️ 429 不在 `docs/统一错误码与鉴权.md` 八值白名单内——属传输层限流响应，已提请 A 确认纳入（见 [挂载请求](../../requests/D/20261107-D-限流中间件挂载请求.md)）。
- 黑名单命中：**403**（code 403 在白名单内），优先于限流计数，不消耗计数。
- 中间件不读写 MySQL；「停服降级直查库」由调用方语义保证（cache get None → 直查库），中间件自身只放行。

## 5. 观测

- `CacheClient.stats()`：`{hits, misses, degraded_ops, errors, enabled, available, hit_ratio}`（进程内计数）。
- `dbsize()` 容量探测；T-D01b 切片接入健康接口/日志暴露，本任务只提供数据源。

## 6. 测试与边界

- 单测：`pytest tests/D -v` → 20 passed（fake 注入，无 Redis 依赖）；真实 Redis 集成用例 1 条（默认 `redis://127.0.0.1:6399/0`，不可达自动 skip）。
- 本机起测试 Redis：`docker run -d --name aitalent-test-redis -p 6399:6379 redis:7-alpine`。
- 未验证项：真实 Redis 服务端联调、A 挂载后的全链路 429/403、命中率≥98% 目标实测（T-D28 性能批次）。
