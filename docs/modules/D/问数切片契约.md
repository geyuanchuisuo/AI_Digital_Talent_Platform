## 8. T-D09 自由问数受控执行（v1.2，2026-11-08）

### 8.1 架构（`analytics/nl2sql/`，纵深防御）

| 层 | 职责 | 失败语义 |
|---|---|---|
| `generator` | 问题 → SQL（OpenAI 兼容 spark/Agnes；无法映射返回 None） | None → 422 拒答不猜测；LLM 未配置/失败 → 503 |
| `validator` | sqlparse SELECT-only：单语句/禁写关键词全树扫描/表引用白名单核对（CTE 别名豁免）/FOR UPDATE 拒绝/强制 LIMIT（无则包装） | 422 不安全 SQL |
| `executor` | 只读事务 `SET TRANSACTION READ ONLY` + `SET LOCAL statement_timeout` + fetchmany(max+1) 截断 | 超时 → 503；只读拒绝 → 422 |
| `whitelist` | 副本 information_schema 发现（表/列）——**列级 allowlist 的落地物即字段白名单执行面** | 不在白名单 → 422 |
| 审计 | `nl2sql_audit`（D_0005，62 表基线）：question/generated_sql/stage/refused_reason/row_count/duration_ms——全链路留痕 | — |

安全模型：问题文本是**不可信输入**（提示注入兜底=校验器+只读事务+副本列级 allowlist）；校验器是快速失败 UX 层，**硬强制在 PG 只读事务与副本 schema**。

### 8.2 端点

- `POST /api/analytics/nl2sql/query` `{question}`（管理侧 admin/hr；≤500 字符）
- 返回：`{question, sql, columns, rows, row_count, truncated, duration_ms, source, audit_id}`

### 8.3 配置（config.py）

- `nl2sql_timeout_seconds=30` / `nl2sql_max_rows=1000`（T-D09 ③ 默认口径，可配置）
- LLM_API_KEY 占位符时生成器 = RefusingGenerator → 422 拒答（不猜测、不假数据）——**等用户填真实 spark/Agnes key 后自动启用真实生成**

### 8.4 验收实测（31 例全绿）

- 负例矩阵：INSERT/UPDATE/DELETE/DROP/TRUNCATE/ALTER/CREATE/GRANT/多语句/CTE 内嵌写/FOR UPDATE/越权表（pg_authid/子查询 hidden_table）——全部 4xx 拦截且审计留痕
- 引号内关键词不误伤（`title='请 DROP TABLE 一下'` 放行）
- 超时实测：`pg_sleep(5)` vs timeout 3s → statement_timeout 取消 → 503
- 行上限实测：`generate_series(1,5000)` → 截断 1000 行 + truncated 标记
- 只读兜底实测：INSERT 直连副本被 PG 只读事务拒绝
- 拒答实测：CANNOT_ANSWER → 422 审计 refused_unmappable


## 9. T-D10 多维分析、自动出图与决策建议（v1.3，2026-11-08）

### 9.1 多维分组（验收①可复现）

- `DIMENSIONS[metric_id]` 代码注册（与 STAT_FUNCS 同模式）：jobs.active→department、job.demand_progress_gap→project_group、match.threshold_reference→job。
- `GET /metrics/{metric_id}?group_by=dim`；非白名单维度 422「分组维度不在指标允许范围」（awaiting 检查先于维度检查）。
- 复现保证：确定性管道（参数排序归一→缓存键含 group_by→快照留痕逐组合一行）+ 解读规则式无 LLM、不嵌时间戳 ⇒ 同组合跨缓存状态逐字段一致。

### 9.2 自动出图（验收③图表数据与表格一致）

- `charts.py build_chart`：图表数据**只从同一响应 table.rows 派生**（构造保证）；
- 类型确定性选择：暂无数据→none；纯标量→number；行+配置绘图列→bar（序列截断 20 项）；
- 绘图列按 (metric_id, group_by) 声明于 `CHART_COLUMNS`（gap→position_name/project_group，threshold→title/ratio，active→department）；
- **数值守卫（D26，2026-11-11）**：绘制窗口内出现 None/bool/字符串等非数值 → `none` + reason「数值列含非数值，无法绘图」，不渲染误导柱高；窗口外的坏值不影响已绘制的前 20 点（一致性只核对渲染出的点）；
- **截断可见（D26）**：网页端 bar 图在 `truncated_series=true` 时于图下显示「仅显示前 N 项（共 M 项，其余未绘制）」（M 取 `table.rows.length`），不再静默裁掉长尾；文档导出侧同口径标注；
- 测试：逐点核对 series == table.rows、Σseries == value、none/number/bar 形态、截断标记与边界（19/20/21 项）、单序列、缺列/未登记组合、非数值守卫（`tests/D/test_analytics_charts_d26.py` 25 例 + `page.test.tsx` 4 例）。

### 9.3 决策建议（验收②事实/推断机器可区分）

- `insight.py build_interpretation`：分段 `{kind: fact|inference, key, text, ref?, basis?}`；
- fact 只复述查询数字（ref 携带引用值）；inference 模板化建议且 `basis` 显式引用依据；
- **不把相关说成因果**：模板全建议/分布措辞 + `_CAUSAL_WORDS` 扫描守卫（has_causal_language，测试断言零命中）；
- 规则式实现（generator="rule"）不依赖 LLM——同数据 ⇒ 解读可复现；LLM 增强待 Key 后按同分段契约接入。

### 9.4 快照扩展

`analytics_query_snapshots.result_json` 现含 {value, table, group_by, chart, interpretation}——T-D11 同快照导出、T-D12 反馈引用均以此为单一事实源。

## 11. T-D11 同快照 DOCX/PDF 导出（v1.5，2026-11-08）

### 11.1 端点与模块

- `backend/app/modules/reports/`（新：service/router/models）+ `snapshot_export_audit` 表（D_0007，**64 表基线**）。
- `GET /api/reports/snapshots/{snapshot_id}/export?format=docx|pdf`——返回文件流（Content-Disposition 带文件名）。
- 未知格式 422；未知快照 404。

### 11.2 权限与审计

- 导出前**重新校验权限**：管理侧（can_view_all_persons）或快照创建者；否则 403。
- 每次导出写 `snapshot_export_audit` 一行（谁/何时/格式/快照）。

### 11.3 同快照保证（验收②）

构建输入**只有**快照 result_json（value/table/interpretation/chart）与元数据——不触达任何统计函数（哨兵断言）、不重新问数。

### 11.4 内容与如实显示（验收①④）

- 中文：DOCX 东亚字体显式设置（微软雅黑）；PDF 用 reportlab 内置 CID 字体 STSong-Light（无需外部字体文件）。
- 长表分页：PDF platypus Table（repeatRows 表头逐页重复）；DOCX 由 Word 自身分页。
- **图形嵌入（PRD D16，2026-11-11 起）**：`chart` 规格经 `reports/chart_render.py` 渲染为**确定性 PNG**（Pillow 自绘，零新增依赖）嵌入导出物——bar（含截断标注/负值基线/20 项上限）与 number（数值卡）两型；`none` 与未知类型不嵌图。图形节（"图表"）在前，"图表数据"数值表保留为附录；截断如实标注「（图表数据已截断）/（仅显示前 20 项）」。
- **渲染确定性**：纯函数、同输入字节级同输出（PNG 无时间戳）；不触库、不重算——同快照导出的可复现基础，重问数仍由哨兵断言把关。
- **中文字体**：渲染器按候选路径探测 CJK 字体（Windows 微软雅黑/黑体、Linux 文泉驿/Noto、macOS 苹方），全部缺失退回 PIL 默认字体（中文不可渲染但不崩溃）——部署环境须保证任一候选存在。
- 空数据/无解读：如实写「（暂无数据）/（无数据行）/（无解读）」。
- 自由问数（nl2sql）结果当前不产出 chart 规格；其链路随 D14 交付后自动复用本渲染器与导出管线。交互式图表仍在网页端（D26/T-D20 看板），文档导出为位图嵌入。
