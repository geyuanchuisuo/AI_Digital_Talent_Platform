## 3. 切片暴露的集成问题清单（T-D01b 验收③）

1. **redis.asyncio 跨事件循环崩溃**（已修复）：CacheClient 全局实例在多次 `asyncio.run` 的脚本/测试里报 "Event loop is closed"——已按运行循环重建底层连接（`client.py:_client`），回归测试 `test_client_rebinds_across_event_loops`（真实 Redis 6399）。FastAPI 单循环场景本就无恙。
2. **models 直连入口循环导入**（既有约束，登记）：`app.modules.analytics.models` 不能作为 import 入口（C 域同款纪律），消费方一律先 `import app.models` 或经包导入；uvicorn 路径无恙（deps 先加载 app.models）。
3. **mysql 双引号陷阱**（ETL 已修）：MySQL 默认 SQL 模式下 `"id"` 是字符串字面量——副本源查询必须反引号（etl_pgsql.py 已带回归）。
4. **前端测试基建**：jest-dom 未安装，断言用 `toBeTruthy()` 惯例（与既有页面测试一致）。
