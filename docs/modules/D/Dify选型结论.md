# Dify 社区版选型结论（T-D00d）

> 版本：v0.1　|　日期：2026-11-07　|　维护：D　|　性质：选型评审结论（待 MASTER/用户复核）
> 依据：统一需求 V2.6 §1（Dify 为原始指定组件，必须落地）；§16 D-05（私有化社区版+版本锁定）

## 1. 结论

**采用 Dify 私有化社区版（self-hosted Community Edition）承载可视化编排与 Agent 中台管控**；自研 agent_management/agent_publish/agent_workflow/model_provider 模块改造为 Dify API 对接层。回退边界：Dify 不可用时表单/模板配置兜底（V2.6 确认的合法补充路径）。

## 2. 版本与部署

- 部署形态：Docker Compose 私有化部署（与现有 deploy/ 体系一致），版本在部署时锁定并登记（升级须演练，T-D05 验收项）
- 具体版本号：**部署时以官方 stable release 为准锁定**（本文不预填具体版本号，避免凭记忆猜测过期）
- 数据边界：Dify 自带数据库与业务库分离；D 域业务数据落库回写自研侧，Dify 仅承载编排配置与运行记录

## 3. 许可条款核对（要点，部署时以官方 LICENSE 复核）

- Dify 主许可为「Apache 2.0 修改版」：允许内部商用与自托管；**限制多租户 SaaS 转售、移除/替换品牌标识（logo/copyright）需商业授权**
- 本项目为单一企业内部平台（非多租户 SaaS 对外运营）→ 社区版可用
- 若客户场景出现多租户对外运营或品牌定制需求 → 升级企业版或书面豁免，届时另走采购决策
- 复核方式：部署镜像内 `/LICENSE` 文件 + 官方仓库 LICENSE 逐条对照，结论回填本文件

## 4. 与自研模块的对接边界

| 职责 | Dify | 自研 agent_* |
|---|---|---|
| 可视化编排画布、应用发布 UI | ✅ 承载 | API 对接层 |
| 流程运行数据/业务落库 | 运行记录 | ✅ 回写业务库 |
| 模型供应商配置 | 平台侧模型管理 | ✅ 业务密钥配置（本地安全读取） |
| 权限/审计 | 平台登录 | ✅ 业务权限与审计 |

## 5. 回退方案（三要素）

1. 触发条件：Dify 服务不可用 / 许可风险 / 版本升级失败
2. 回退动作：切换表单/模板配置路径（V2.6 确认的合法补充），流程定义与运行数据在自研落库不受影响
3. 责任人：D；升级演练由 D 执行并登记
