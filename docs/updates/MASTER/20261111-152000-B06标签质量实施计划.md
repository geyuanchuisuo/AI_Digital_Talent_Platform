- 标签和来源确认审计同事务保存于现有TalentProfileEdit私有字段，记录输入/结果版本、原文证据、实际标签行ID和人工原因，不新增表/迁移/公共注册；没有依据的手工标签仍允许，但不得显示为“原文已确认”。
- GET /talents/{id}/tag-quality按现有读权限提供当前标签来源核对；引用失效或标签列表重建后，旧确认不能自动恢复。个人读者不获得内部复核原因/操作者；确认不等于能力评级。
- 前端TagSuggestions显示语境及多引用，可填写复核原因并加入草稿；TagEditModal只有最终保存才提交proof。档案版本变化/来源失效返回409保留草稿；选择普通目录词没有原文proof。质量视图显示未证实/已确认/待重核，不展示虚假通过率。
