## 发现的两个缺陷（本记录修复）

1. **自定义前端端口起不来**：`npm exec next dev -p <port>` 中的 `-p` 被 npm 当作自身选项吞掉，Next 把端口当项目目录，报 `Invalid project directory provided, no such directory: ...\frontend\3100`，前端进程提前退出，`start_services` 检测到退出后 break。默认 3000 端口走 `npm run dev` 不受影响，但 README/`.env.example` 都允许 `FRONTEND_PORT` 覆盖，属交付缺陷。
2. **Windows 下服务停不干净**：原 `Popen(..., shell=True)` 起的是 `cmd.exe`，`terminate()` 只杀 shell，uvicorn 变成孤儿进程继续监听（实测 PID 19716 在前端退出后仍返回 health 200）。

## 修复内容

- 直接用 `node + node_modules/next/dist/bin/next dev -p <port>` 启动前端，绕开 npm 参数解析；`next` CLI 不存在时才回退到 `npm exec -- next dev -p <port>`（补 `--` 分隔）。
- 后端与前端的 `Popen` 均改为 `shell=False`（回退分支除外），使 `Ctrl+C` / 提前退出时的 `terminate()` 能真正结束进程。
