## 一、改动设计

`with_purpose()` 工厂已就绪但要求调用方改用实例——10 个调用点全是模块级 `chat_json`，逐个换实例侵入大。本轮改法：**purpose 作为单次调用参数沿 `chat_json → _chat_raw → _record_call` 透传**（`None=用实例默认`），调用方一行改动；实例级 `with_purpose` 仍可用（向后兼容）。 purpose 命名对齐业务域（`{domain}_{action}` 蛇形），中台看板可按域聚合。
