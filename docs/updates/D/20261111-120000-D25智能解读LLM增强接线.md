## 代码改动

- `backend/app/config.py`
  - 新增 `analytics_llm_insight_enabled`，默认 `False`。
- `backend/app/modules/analytics/insight.py`
  - 新增 `build_interpretation_with_llm()`：规则解读打底，LLM 仅在开关开启时增补 `inference` 段。
  - LLM 返回结构使用 Pydantic `_EnhanceList`；非法结构、调用失败或超时回退 `generator="rule"`。
  - `basis` 只接受已有事实段 key；无有效依据的增补段丢弃。
  - 增补段继续使用因果措辞守卫，违规整段丢弃。
  - 增加模块 logger。
- `backend/app/modules/analytics/service.py`
  - 指标查询改用 `build_interpretation_with_llm()`；默认开关关闭时不改变既有规则解读结果。
- `tests/D/test_analytics_d25.py`
  - 新增 6 个专项用例：默认关闭、显式关闭、正常增补、失败回退、无效依据丢弃、因果措辞丢弃。

## 契约与边界

- 规则段始终保留，LLM 不可用不影响指标查询。
- 默认关闭，部署方通过 `ANALYTICS_LLM_INSIGHT_ENABLED=true` 显式开启。
- LLM 只能增补推断段，不得改写事实段；因果措辞会被丢弃。
- 本实现不改变 D14 的 Vanna 原生集成状态，不把普通 LLM 解读等同于 Vanna 问数完成。
- D13 指标目录的 B/C 口径仍未回传，本轮未擅自补 SQL。
- D02 代码和 fake Redis 测试已存在，真实 Redis 限流/降级仍需集中验收。
- D07 依赖 B/C 生产方；D09/D10 依赖真实 Dify；D22 尚未接检索主链，均不能据本轮宣称完成。
