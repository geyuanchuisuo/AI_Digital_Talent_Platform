## 一、设计要点

1. **零新增依赖**：matplotlib 缺失且按根规则 §3 加包须走 A 的依赖清单请求。图表形态仅 bar/number 两类，Pillow（既有）自绘完全覆盖——柱图含横向网格、5 档刻度、柱端数值标注、类目标签（>8 字截断）、负值基线处理、截断标注；规避依赖请求阻塞。
2. **确定性渲染**：渲染器为纯函数——只读 chart 规格字典，不触库、不重算、不含时间戳；同输入字节级同输出（测试断言）。同快照保证的双保险：chart 数据本就只从同一 table 派生（T-D10 构造保证）+ 渲染确定性（本条）+ 重问数哨兵（D11 既有）。
3. **中文字体**：候选路径探测（Windows 微软雅黑/黑体 → Linux 文泉驿/Noto CJK → macOS 苹方），本机实核 msyh.ttc/simhei.ttf 均在；全部缺失退回 PIL 默认位图字体（中文不可渲染但不崩溃）——部署边界登记。
4. **实现坑（供避坑）**：ORM `JSONDict` 是 `MutableDict`（dict 子类），PyYAML 按精确类型查找 representer → `RepresenterError`，进 YAML/比较前须 `_plain()` 递归转纯容器；测试文件首个 `app.models` 触达若发生在 `reports.service` 导入链内部会撞半初始化环——测试文件顶部先 `import app.models` 完成注册。
