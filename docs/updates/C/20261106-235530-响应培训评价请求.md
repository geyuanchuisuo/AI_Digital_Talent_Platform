## 逐条回应

| D 请求规则 | C 实现 |
| --- | --- |
| 课程结束后，仅该期次有签到/出勤记录的实际参加员工可评价 | `TrainingAttendance` 按期次登记；无出勤返回 403；课程未结束窗口不开放 |
| 课程内容、讲师分别 1–5 分 | `content_score`、`instructor_score` 均为 1–5，提交接口强校验 |
| 评价非完成条件、不影响能力评级 | 评价表与学习记录、成长事件完全分离，不参与任何评级计算 |

| 同一员工同一课程跨期最多一份有效反馈 | `uk_feedback_course_employee` 唯一约束，跨期/跨讲师更新同一行 |
| 少于 5 份不展示汇总；达到 5 份立即展示并持续更新 | 汇总按提交状态实时计算；<5 只返回份数，不返回均分与主题 |

| 文字意见不展示原文，仅展示主题归纳；单主题至少 5 份支持 | `c-training-feedback-theme-v1` 真实模型归纳；仅存储/返回 ≥5 份支持的主题，接口不含原文与员工身份 |
| 讲师/部门经理不能逐条公开回复 | 未提供逐条反馈或回复接口 |
| 培训管理员可发布统一改进说明 | `PUT /feedback-note`，员工在本人评价状态中可见；不改课程版本 |
| 匿名内容不得反推员工，实名调查另走独立渠道 | 汇总与主题接口不返回员工字段；未实现实名调查，未与匿名内容关联 |
| 越权访问不可用 | 评价仅员工本人；汇总/期次/出勤/说明仅 `admin/hr`；其余角色 403 |
